# Five Essential Characteristics of Cloud Computing

Cloud computing is commonly described using five essential characteristics.

## 1. On-demand self-service

Users can provision available computing resources themselves when needed, without requiring a person at the provider to manually fulfil every request.

**Example:** An authorized employee creates a virtual machine through a cloud console instead of waiting for a physical server to be purchased and installed.

## 2. Broad network access

Cloud services are available over a network and can be accessed from suitable devices, such as laptops, phones, and tablets.

**Example:** Accessing an online storage service from both a laptop and a phone.

## 3. Resource pooling

A provider pools computing resources to serve multiple customers. Resources are allocated and managed according to each customer's needs, with appropriate isolation.

**Example:** A cloud provider operates a large infrastructure platform that serves many different customers.

## 4. Rapid elasticity

Resources can often be increased or decreased quickly to match changing demand.

**Example:** An online shop may add computing capacity during a busy sale and reduce it when traffic returns to normal.

**Remember:** Elasticity means resources can expand or shrink as needed.

## 5. Measured service

Cloud usage is measured, monitored, and reported. Many services charge based on usage, resource size, duration, or another pricing unit.

**Example:** A company reviews its storage usage and the related charges on its cloud bill.

**Note:** Not every cloud service charges only by the amount used. Always check the service's pricing model.

## Quick revision table

| Characteristic | Simple meaning | Example |
|---|---|---|
| On-demand self-service | Get resources yourself when needed | Create a virtual machine |
| Broad network access | Access services through a network | Open cloud files on a phone |
| Resource pooling | Provider resources serve multiple customers | Shared provider infrastructure |
| Rapid elasticity | Increase or decrease capacity | Scale during high traffic |
| Measured service | Usage is monitored and measured | Review storage consumption |

## Key takeaway

These characteristics make cloud resources easier to obtain, access, share efficiently, scale, and measure.
