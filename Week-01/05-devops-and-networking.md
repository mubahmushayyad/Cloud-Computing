# Introduction to DevOps and Networking

## 1. What is DevOps?

**DevOps** is a set of practices and a working culture that brings software development (Dev) and IT operations (Ops) closer together. Its aim is to deliver software more reliably and efficiently through collaboration, automation, testing, deployment, and monitoring.

DevOps can be used with on-premises systems, cloud systems, or a combination of both. It often includes coding and automation, but it is not only coding.

### Why is DevOps useful?
- Encourages collaboration between development and operations teams.
- Helps automate repetitive tasks.
- Supports consistent testing and deployment.
- Helps teams deliver updates more reliably.
- Encourages monitoring and continuous improvement.

## 2. HTTP and HTTPS

- **HTTP** stands for Hypertext Transfer Protocol. It is used to transfer web resources between clients and servers.
- **HTTPS** is HTTP protected by TLS, which helps encrypt communication and authenticate the server.

**Example:** A browser uses HTTPS when securely connecting to a website that supports it.

## 3. What is SSH?

**SSH** stands for Secure Shell. It is a protocol commonly used to securely access and manage a remote computer or server through a command-line interface.

**Example:** An administrator connects to a Linux server remotely to run commands.

## 4. What is a network port?

A **port** is a numbered endpoint used by network protocols to direct communication to the appropriate application or service on a device.

Common default ports include:
- HTTP: TCP port 80
- HTTPS: TCP port 443
- SSH: TCP port 22

These are common defaults; services can be configured to use other ports. A port number alone does not guarantee that a service is reachable or secure.

## 5. A useful method for learning a new technology

When exploring a technology or vendor, ask:

1. What is it?
2. What problem does it solve?
3. Which major vendors provide it?
4. What are its common features and functions?
5. How can I practise it in a small lab?

This method can help structure learning about routers, cloud services, security tools, and other infrastructure technologies.

## Key takeaway

DevOps helps teams build and operate software more effectively. HTTP/HTTPS, SSH, and ports are foundational networking concepts that help explain how applications and administrators communicate with systems.
